# Spec Delta

## ADDED Requirements

### Requirement: Выбор выборки в UI
Блок «Резюме и рынок» MUST запоминать в браузере выбранные «Вакансий» (50, 100, 200, 300, 500) и «Грейд»; хранилище недоступно — блок работает с выбором по умолчанию (100, все грейды). Карьерный отчёт SHALL строить раздел рынка по той же выборке; при выбранном грейде он не показывает распределение грейдов и не называет этот грейд уровнем, которым рынок видит резюме.

#### Scenario: Отчёт по сеньорскому рынку
- **WHEN** в блоке выбран грейд `senior`, и открыт карьерный отчёт
- **THEN** раздел рынка подписан «грейда senior», колонки «Грейды» нет
